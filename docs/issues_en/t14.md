## DA Gating Architecture

### Overview

**Data Availability (DA) Gating** ensures validators only vote on anchors for which they have local data.

**Key Principle: Pull-then-Vote**
```
1. Receive anchor header announcement (with payload_hash)
2. Check if payload exists locally
3. If not:
   a. Request payload from peers (GetPayloads)
   b. Wait for payload arrival (with timeout)
   c. Verify payload matches payload_hash
4. Only after successful data availability:
   → Proceed with voting/finalization
5. If timeout/failure:
   → Do NOT vote, log warning
```

**Why DA Gating Matters:**
- **Data Withholding Attack Prevention:** Malicious proposers cannot create anchors with unavailable data
- **Network Health:** Ensures all finalized anchors have recoverable data
- **Validator Accountability:** Validators attest only to data they possess

### Components

**DaGatingManager:**
- Tracks pending data requests
- Enforces pull-then-vote workflow
- Manages timeouts and retries
- Provides clear accept/reject decisions

**StorageInterface:**
- Check if payload exists locally
- Store received payloads
- Retrieve payloads by root hash

**FetcherInterface:**
- Request payloads from P2P network
- Track in-flight requests
- Handle responses and failures

## Pull-then-Vote Workflow

### Normal Flow (Data Available)

```
┌─────────────┐
│ Peer        │
└──────┬──────┘
       │ HeaderAnnounce(payload_hash=H)
       ▼
┌──────────────────────────────┐
│ DaGatingManager              │
│ - Check local storage for H  │
└──────┬───────────────────────┘
       │
       ├─ Found locally?
       │  ├─ YES → ✅ Proceed to vote
       │  └─ NO  → Continue ▼
       │
       ▼
┌──────────────────────────────┐
│ Request payload via P2P      │
│ - GetPayloads(roots=[H])     │
│ - Track pending request      │
│ - Start timeout timer        │
└──────┬───────────────────────┘
       │ Wait for payload...
       ▼
┌──────────────────────────────┐
│ PayloadResponse received     │
│ - Verify root matches H      │
│ - Store in local storage     │
└──────┬───────────────────────┘
       │
       ▼
  ✅ DATA AVAILABLE
       │
       ▼
┌──────────────────────────────┐
│ Proceed with vote/finalize   │
└──────────────────────────────┘
```

### Failure Flow (Data Unavailable)

```
┌─────────────┐
│ Peer        │
└──────┬──────┘
       │ HeaderAnnounce(payload_hash=H)
       ▼
┌──────────────────────────────┐
│ DaGatingManager              │
│ - Check local storage for H  │
│ - NOT found locally          │
└──────┬───────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ Request payload via P2P      │
│ - GetPayloads(roots=[H])     │
│ - Start timeout (e.g., 5s)   │
└──────┬───────────────────────┘
       │ Wait...
       │
       ├─ Timeout expired?
       │  ├─ Payload arrived → ✅ Proceed
       │  └─ Still missing   → ❌ Reject ▼
       │
       ▼
  ❌ TIMEOUT / DATA UNAVAILABLE
       │
       ▼
┌──────────────────────────────┐
│ REJECT vote                  │
│ - Log warning                │
│ - Mark anchor as unavailable │
│ - Continue monitoring        │
└──────────────────────────────┘
```

## DaGatingManager Implementation

### Data Structures

```rust
pub struct DaGatingManager<S: StorageInterface, F: FetcherInterface> {
    storage: Arc<S>,
    fetcher: Arc<F>,
    pending: Arc<Mutex<HashMap<Hash32, PendingRequest>>>,
    config: DaGatingConfig,
}

pub struct PendingRequest {
    pub payload_hash: Hash32,
    pub requested_at: Instant,
    pub timeout: Duration,
    pub notifiers: Vec<oneshot::Sender<DaResult>>,
}

pub struct DaGatingConfig {
    pub fetch_timeout: Duration,        // Default: 5s
    pub max_pending: usize,             // Default: 1000
    pub retry_attempts: u32,            // Default: 3
    pub retry_delay: Duration,          // Default: 1s
}

pub enum DaResult {
    Available(Vec<u8>),      // Payload data
    Timeout,                 // Timed out
    Invalid,                 // Root mismatch
    Unreachable,             // Network error
}
```

### Core Methods

```rust
impl<S: StorageInterface, F: FetcherInterface> DaGatingManager<S, F> {
    /// Check if data is available, fetch if not
    pub async fn ensure_data_available(
        &self,
        payload_hash: Hash32,
    ) -> Result<DaResult, DaGatingError> {
        // 1. Check local storage
        if let Some(data) = self.storage.get(&payload_hash).await? {
            return Ok(DaResult::Available(data));
        }

        // 2. Check if already pending
        {
            let pending = self.pending.lock().await;
            if pending.contains_key(&payload_hash) {
                // Already in flight, attach to existing request
                return self.wait_for_pending(payload_hash).await;
            }
        }

        // 3. Initiate fetch
        self.fetch_and_wait(payload_hash).await
    }

    /// Fetch payload and wait for result
    async fn fetch_and_wait(
        &self,
        payload_hash: Hash32,
    ) -> Result<DaResult, DaGatingError> {
        let (tx, rx) = oneshot::channel();

        // Register pending request
        {
            let mut pending = self.pending.lock().await;
            if pending.len() >= self.config.max_pending {
                return Err(DaGatingError::TooManyPending);
            }

            pending.insert(
                payload_hash,
                PendingRequest {
                    payload_hash,
                    requested_at: Instant::now(),
                    timeout: self.config.fetch_timeout,
                    notifiers: vec![tx],
                },
            );
        }

        // Send fetch request
        self.fetcher.request_payload(payload_hash).await?;

        // Wait for result or timeout
        match tokio::time::timeout(self.config.fetch_timeout, rx).await {
            Ok(Ok(result)) => Ok(result),
            Ok(Err(_)) => Ok(DaResult::Unreachable),
            Err(_) => {
                // Timeout
                self.cleanup_pending(payload_hash).await;
                Ok(DaResult::Timeout)
            }
        }
    }

    /// Handle incoming payload response
    pub async fn handle_payload_response(
        &self,
        payload: AnchorPayload,
    ) -> Result<(), DaGatingError> {
        let payload_hash = payload_merkle_root(&payload);

        // Store payload
        self.storage.put(&payload_hash, &payload).await?;

        // Notify waiters
        let notifiers = {
            let mut pending = self.pending.lock().await;
            pending.remove(&payload_hash).map(|req| req.notifiers)
        };

        if let Some(notifiers) = notifiers {
            let data = serde_json::to_vec(&payload)?;
            for tx in notifiers {
                let _ = tx.send(DaResult::Available(data.clone()));
            }
        }

        Ok(())
    }

    /// Check if data is locally available (no fetch)
    pub async fn is_available(&self, payload_hash: &Hash32) -> bool {
        self.storage.get(payload_hash).await.ok().flatten().is_some()
    }

    /// Wait for already-pending request
    async fn wait_for_pending(
        &self,
        payload_hash: Hash32,
    ) -> Result<DaResult, DaGatingError> {
        let (tx, rx) = oneshot::channel();

        // Attach to existing request
        {
            let mut pending = self.pending.lock().await;
            if let Some(req) = pending.get_mut(&payload_hash) {
                req.notifiers.push(tx);
            } else {
                // Race: request completed between checks
                return self.ensure_data_available(payload_hash).await;
            }
        }

        // Wait for result
        match tokio::time::timeout(self.config.fetch_timeout, rx).await {
            Ok(Ok(result)) => Ok(result),
            Ok(Err(_)) => Ok(DaResult::Unreachable),
            Err(_) => Ok(DaResult::Timeout),
        }
    }

    /// Cleanup expired pending requests
    async fn cleanup_pending(&self, payload_hash: Hash32) {
        let mut pending = self.pending.lock().await;
        pending.remove(&payload_hash);
    }

    /// Periodic cleanup of stale requests
    pub async fn cleanup_stale(&self) {
        let mut pending = self.pending.lock().await;
        let now = Instant::now();
        pending.retain(|_, req| {
            now.duration_since(req.requested_at) < req.timeout * 2
        });
    }
}
```

## Storage Interface

```rust
#[async_trait]
pub trait StorageInterface: Send + Sync + 'static {
    /// Check if payload exists locally
    async fn get(&self, payload_hash: &Hash32) -> Result<Option<Vec<u8>>, StorageError>;

    /// Store payload locally
    async fn put(&self, payload_hash: &Hash32, payload: &AnchorPayload) -> Result<(), StorageError>;

    /// Delete payload (for cleanup)
    async fn delete(&self, payload_hash: &Hash32) -> Result<(), StorageError>;

    /// List all stored payload hashes
    async fn list(&self) -> Result<Vec<Hash32>, StorageError>;
}

/// In-memory implementation for testing
pub struct InMemoryStorage {
    store: Arc<Mutex<HashMap<Hash32, Vec<u8>>>>,
}

#[async_trait]
impl StorageInterface for InMemoryStorage {
    async fn get(&self, payload_hash: &Hash32) -> Result<Option<Vec<u8>>, StorageError> {
        let store = self.store.lock().await;
        Ok(store.get(payload_hash).cloned())
    }

    async fn put(&self, payload_hash: &Hash32, payload: &AnchorPayload) -> Result<(), StorageError> {
        let data = serde_json::to_vec(payload)?;
        let mut store = self.store.lock().await;
        store.insert(*payload_hash, data);
        Ok(())
    }

    async fn delete(&self, payload_hash: &Hash32) -> Result<(), StorageError> {
        let mut store = self.store.lock().await;
        store.remove(payload_hash);
        Ok(())
    }

    async fn list(&self) -> Result<Vec<Hash32>, StorageError> {
        let store = self.store.lock().await;
        Ok(store.keys().copied().collect())
    }
}
```

## Fetcher Interface

```rust
#[async_trait]
pub trait FetcherInterface: Send + Sync + 'static {
    /// Request payload from P2P network
    async fn request_payload(&self, payload_hash: Hash32) -> Result<(), FetcherError>;

    /// Request multiple payloads
    async fn request_payloads(&self, payload_hashes: Vec<Hash32>) -> Result<(), FetcherError>;

    /// Check if request is in flight
    async fn is_pending(&self, payload_hash: &Hash32) -> bool;
}

/// P2P-based fetcher implementation
pub struct P2pFetcher {
    p2p_service: Arc<P2pService>,
    pending: Arc<Mutex<HashSet<Hash32>>>,
}

#[async_trait]
impl FetcherInterface for P2pFetcher {
    async fn request_payload(&self, payload_hash: Hash32) -> Result<(), FetcherError> {
        // Mark as pending
        {
            let mut pending = self.pending.lock().await;
            if pending.contains(&payload_hash) {
                return Ok(()); // Already requested
            }
            pending.insert(payload_hash);
        }

        // Send GetPayloads request
        self.p2p_service
            .send_message(P2pMessage::Req(ReqMsg::GetPayloads {
                roots: vec![payload_hash],
            }))
            .await
            .map_err(|e| FetcherError::NetworkError(e.to_string()))?;

        Ok(())
    }

    async fn request_payloads(&self, payload_hashes: Vec<Hash32>) -> Result<(), FetcherError> {
        let mut pending = self.pending.lock().await;
        let new_hashes: Vec<Hash32> = payload_hashes
            .into_iter()
            .filter(|h| !pending.contains(h))
            .collect();

        for h in &new_hashes {
            pending.insert(*h);
        }

        if new_hashes.is_empty() {
            return Ok(());
        }

        self.p2p_service
            .send_message(P2pMessage::Req(ReqMsg::GetPayloads {
                roots: new_hashes,
            }))
            .await
            .map_err(|e| FetcherError::NetworkError(e.to_string()))?;

        Ok(())
    }

    async fn is_pending(&self, payload_hash: &Hash32) -> bool {
        let pending = self.pending.lock().await;
        pending.contains(payload_hash)
    }
}
```

## Strict Gating Enforcement

### Vote Gating

**Rule:** Validator MUST NOT vote on anchor unless payload is locally available.

```rust
pub async fn should_vote_on_anchor(
    &self,
    header: &AnchorHeader,
) -> Result<bool, DaGatingError> {
    let payload_hash = header.payload_hash;

    // Strict check: data must be available
    match self.da_manager.ensure_data_available(payload_hash).await? {
        DaResult::Available(_) => Ok(true),   // ✅ Can vote
        DaResult::Timeout => Ok(false),       // ❌ Cannot vote
        DaResult::Invalid => Ok(false),       // ❌ Cannot vote
        DaResult::Unreachable => Ok(false),   // ❌ Cannot vote
    }
}
```

### Finalization Gating

**Rule:** Validator MUST NOT finalize anchor unless payload is locally available.

```rust
pub async fn should_finalize_anchor(
    &self,
    header: &AnchorHeader,
) -> Result<bool, DaGatingError> {
    let payload_hash = header.payload_hash;

    // Even stricter: must be already available (no waiting)
    if self.da_manager.is_available(&payload_hash).await {
        Ok(true)  // ✅ Can finalize
    } else {
        // Try to fetch with timeout
        match self.da_manager.ensure_data_available(payload_hash).await? {
            DaResult::Available(_) => Ok(true),
            _ => Ok(false),
        }
    }
}
```

## Timeout Scenarios

### Non-Delivery (Data Never Arrives)

**Scenario:** Malicious/faulty proposer announces header but doesn't provide payload.

**Handling:**
1. DaGatingManager requests payload via P2P
2. Waits for `fetch_timeout` (e.g., 5s)
3. If timeout expires without response:
   - Return `DaResult::Timeout`
   - Do NOT vote on anchor
   - Log warning: "DA timeout for anchor X"
   - Optionally: track proposer for slashing evidence

**Code:**
```rust
match da_manager.ensure_data_available(payload_hash).await? {
    DaResult::Timeout => {
        warn!("DA timeout for payload {}", hex::encode(payload_hash));
        // Do not vote
        return Ok(false);
    }
    _ => {}
}
```

### Late Delivery (Data Arrives After Timeout)

**Scenario:** Payload arrives after voting window has closed.

**Handling:**
1. Payload stored in local storage when it arrives
2. But validator already timed out and didn't vote
3. Future anchors referencing this payload can now proceed
4. No retroactive voting on past anchors

**Code:**
```rust
// Payload arrives late
da_manager.handle_payload_response(payload).await?;
// → Stored locally, but voting window for anchor already passed
// → OK: future references to this payload will succeed
```

### Partial Delivery (Some Data Missing)

**Scenario:** Anchor references multiple payloads, only some are available.

**Handling:**
1. Check all required payloads
2. If ANY payload missing/timed out → do NOT vote
3. All-or-nothing policy ensures complete data availability

**Code:**
```rust
let mut all_available = true;
for payload_hash in required_payloads {
    match da_manager.ensure_data_available(payload_hash).await? {
        DaResult::Available(_) => continue,
        _ => {
            all_available = false;
            break;
        }
    }
}
if !all_available {
    return Ok(false); // Do not vote
}
```

## Security Considerations

### Data Withholding Attack

**Attack:** Malicious proposer creates valid header but withholds payload.

**Mitigation:**
- DA gating ensures validators don't vote without data
- Anchor cannot reach finality threshold
- Network progresses on alternative anchors
- Malicious proposer loses rewards (no finalization)

### DOS via Fake Requests

**Attack:** Attacker floods validator with fake payload requests.

**Mitigation:**
- `max_pending` limit (e.g., 1000 concurrent requests)
- `cleanup_stale()` removes expired requests
- Rate limiting on P2P layer

### Root Mismatch Attack

**Attack:** Peer sends wrong payload for requested root.

**Mitigation:**
- Always verify `payload_merkle_root(payload) == requested_hash`
- Reject mismatched payloads
- Return `DaResult::Invalid`
- Optionally: ban peer sending invalid data

- Local hit: O(1) hashmap lookup (~μs)

## Troubleshooting Guide

### High Timeout Rate

**Symptoms:** Many `DaResult::Timeout` returns

**Causes:**
1. Network issues (peers unreachable)
2. Malicious proposers withholding data
3. `fetch_timeout` too short

**Solutions:**
- Increase `fetch_timeout` (e.g., 5s → 10s)
- Check P2P connectivity
- Monitor proposer reputation

### Storage Growing Unbounded

**Symptoms:** Storage size increasing without limit

**Causes:**
1. No cleanup of old payloads
2. Many unique payloads stored

**Solutions:**
- Implement periodic cleanup of finalized anchors
- Set storage size limits
- Use LRU eviction policy

### Memory Leak (Pending Requests)

**Symptoms:** `pc_da_gating_pending_count` keeps increasing

**Causes:**
1. Timeouts not cleaning up properly
2. `cleanup_stale()` not running

**Solutions:**
- Ensure `cleanup_stale()` runs periodically
- Check timeout logic in `fetch_and_wait()`
- Verify notifier channels are dropped
