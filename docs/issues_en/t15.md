## UTXO State Architecture

### Overview

**UTXO (Unspent Transaction Output) State Engine** manages the current set of spendable outputs on-chain.

**Key Properties:**
- **Deterministic:** Same inputs → same state → same Merkle root
- **Persistent:** RocksDB backend with NVMe optimization
- **Efficient:** O(1) lookups, O(log n) Merkle updates
- **Prunable:** Old state can be removed to save disk space
- **Snapshotable:** Full state can be saved/restored for fast sync

**Core Operations:**
```
1. Apply Mint:
   - Create new UTXOs from mined blocks
   - Track minting time for maturity checks

2. Apply MicroTx:
   - Consume inputs (delete UTXOs)
   - Create outputs (add UTXOs)
   - Enforce conservation: sum(inputs) == sum(outputs)

3. Compute Root:
   - Deterministic Merkle root over all UTXOs
   - Domain-separated leaf hashing
   - Sorted by (txid, vout) for determinism

4. Prune:
   - Remove old finalized state
   - Keep recent N anchors
   - Configurable retention policy

5. Snapshot:
   - Serialize full state to disk
   - Metadata (height, root hash)
   - Stakes preserved

6. Restore:
   - Load snapshot from disk
   - Validate integrity
   - Resume from checkpoint
```

```rust
pub fn apply_mint_with_index(&mut self, m: &MintEvent, minted_at_idx: u64) {
```

### Merkle Root Computation

**Deterministic:**
- Sort all UTXOs by (txid, vout)
- Domain-separated leaf hashing
- Merkle tree construction

```rust
pub fn root(&self) -> Hash32 {
    let mut items: Vec<_> = self.backend.iter().collect();
    items.sort_by(|a, b| {
        match a.0.txid.cmp(&b.0.txid) {
            core::cmp::Ordering::Equal => a.0.vout.cmp(&b.0.vout),
            o => o,
        }
    });
    
    const UTXO_LEAF_DOMAIN: &[u8] = b"pc:utxo:leaf:v1\x01";
    let leaves: Vec<Hash32> = items.iter().map(|(op, (amt, lock))| {
        let mut buf = Vec::new();
        buf.extend_from_slice(UTXO_LEAF_DOMAIN);
        buf.extend_from_slice(&op.txid);
        buf.extend_from_slice(&op.vout.to_le_bytes());
        buf.extend_from_slice(&amt.to_le_bytes());
        buf.extend_from_slice(&lock.0);
        blake3_32(&buf)
    }).collect();
    
    merkle_root_hashes(&leaves)
}
```

## Pruning System

### Implementation

```rust
pub fn prune_old_utxos(&mut self, current: u64, retain_anchors: u64) -> usize {
    let cutoff = current.saturating_sub(retain_anchors);
    let mut to_remove: Vec<OutPoint> = Vec::new();
    
    for (op, _val) in self.backend.iter() {
        if let Some(minted) = self.backend.get_minted_at(&op) {
            if minted < cutoff && !self.backend.is_staked(&op) {
                to_remove.push(op);
            }
        }
    }
    
    let count = to_remove.len();
    for op in to_remove {
        self.backend.del(&op);
        self.backend.del_minted_at(&op);
    }
    count
}
```

**Pruning Strategy:**
- Remove UTXOs minted before `current - retain_anchors`
- Preserve staked UTXOs (never prune)
- Configurable retention policy
- Returns count of pruned UTXOs

**Use Cases:**
- Disk space management
- Archive node vs full node
- Periodic cleanup

```rust
    pub utxos: Vec<(OutPoint, Amount, LockCommitment, u64)>,
    pub stakes: Vec<OutPoint>,
}
```

### Create Snapshot

```rust
pub fn create_snapshot(&self, height: u64) -> StateSnapshot {
    let mut utxos = Vec::new();
    let mut stakes = Vec::new();
    let mut total_value = 0u64;
    
    for (op, (amt, lock)) in self.backend.iter() {
        let minted_at = self.backend.get_minted_at(&op).unwrap_or(0);
        utxos.push((op, amt, lock, minted_at));
        total_value = total_value.saturating_add(amt);
        
        if self.backend.is_staked(&op) {
            stakes.push(op);
        }
    }
    
    StateSnapshot {
        metadata: SnapshotMetadata {
            height,
            state_root: self.root(),
            utxo_count: utxos.len() as u64,
            total_value,
            created_at: current_timestamp(),
            version: 1,
        },
        utxos,
        stakes,
    }
}
```

### Restore Snapshot

```rust
pub fn restore_snapshot(&mut self, snapshot: StateSnapshot) -> Result<(), StateError> {
    // Apply all UTXOs from snapshot
    for (op, amt, lock, minted_at) in snapshot.utxos {
        self.backend.put(op, (amt, lock));
        self.backend.set_minted_at(op, minted_at);
    }
    
    // Apply all stakes
    for op in snapshot.stakes {
        self.backend.set_staked(op);
    }
    
    // Verify root matches
    let computed_root = self.root();
    if computed_root != snapshot.metadata.state_root {
        return Err(StateError::SnapshotIntegrityError);
    }
    
    Ok(())
}
```

**Integrity Check:**
- Recompute Merkle root after restore
- Compare with snapshot metadata
- Fail if mismatch detected

**Use Cases:**
- Fast node bootstrapping
- State migration
- Disaster recovery
- Testing

## Performance Characteristics

**UTXO Operations:**
- Get: O(1) (hashmap/RocksDB lookup)
- Put: O(1) (hashmap/RocksDB write)
- Del: O(1) (hashmap/RocksDB delete)
- Root: O(n log n) (sort + Merkle tree)

**Pruning:**
- Time: O(n) (iterate all UTXOs)
- Space: O(k) (k = UTXOs to prune)

**Snapshot:**
- Create: O(n) (iterate all UTXOs)
- Restore: O(n) (apply all UTXOs) + O(n log n) (verify root)

**Memory Usage:**
- InMemory: O(n) where n = UTXO count
- RocksDB: O(1) (disk-based)

**Disk Usage:**
- Per UTXO: 76 bytes (36 key + 40 value)
- 1M UTXOs: ~76 MB
- 10M UTXOs: ~760 MB

```rust
fn enc_key(op: &OutPoint) -> [u8; 36] {
    let mut k = [0u8; 36];
    k[0..32].copy_from_slice(&op.txid);
    k[32..36].copy_from_slice(&op.vout.to_be_bytes());
    k
}
```

**Value Encoding:**
```rust
fn enc_val(v: &(Amount, LockCommitment)) -> [u8; 40] {
    let mut out = [0u8; 40];
    out[0..8].copy_from_slice(&v.0.to_be_bytes());
    out[8..40].copy_from_slice(&v.1.0);
    out
}
```

**Metadata Storage:**
- Minted-at: prefix `ma` + key(36) → value(8)
- Staked: prefix `st` + key(36) → value(1)

- Batch deletes during pruning
- Configurable block cache
- Bloom filters for key lookups
