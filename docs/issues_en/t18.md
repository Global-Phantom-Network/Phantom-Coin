## Quick Start

```bash
# 1. Create genesis_note.bin
cargo run -p phantom-node --bin genesis_bootstrap -- \
  --mempool-dir /var/lib/phantom-coin/data/mempool --network-name "test"

# 2. Run benchmark (5 minutes)
export TP_DURATION_SEC=10 TP_CONC=64 TP_SHARD_IDS=0
cargo bench -p pc-p2p --features "async libp2p" \
  --bench p2p_throughput_bench -- --measurement-time 15

# 3. Aggregate results
cargo run -p pc-p2p --bin bench_agg

# 4. View throughput (ops/s in column 14)
cat target/criterion_agg.csv | grep "p2p_throughput_headers"
```
